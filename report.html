A4/LEARN Imaging Eval

Compares T1-weighted brain-MRI representations on prognosis beyond clinical data and plasma p-tau217, biomarker prediction, anatomy, and longitudinal change. Every representation is compared with conventional volumetrics on the same participants within each task. These are prognostic and representation evaluations; they do not estimate treatment benefit or identify drug responders.

At a glance

One row per representation and one column per task, each showing that task's headline number. Gain columns are the improvement over clinical data and plasma p-tau217 (P1t also includes tau PET). Shading and arrows mark representations whose paired 95% interval against excludes zero: green ▲ is better, red ▼ is worse. Unshaded cells cannot be told apart from the reference. With about 150 comparisons, a handful of marks will appear by chance, so trust patterns across related tasks more than any single cell, and make decisions on the P1 headline.

Prognosis

Does the scan predict cognitive decline beyond what a trial already measures at baseline? The primary target is each participant's PACC slope over every blinded visit (both arms, arm as a covariate), which is more reliable and uses more participants than the week-240 change scored on placebo alone.

Biology and anatomy

How much of the disease biology and basic anatomy can be read from the scan alone. Anatomy tasks are sanity checks: weak performance warrants checking preprocessing and pooling, but does not by itself diagnose a pipeline error.

Longitudinal change: A4 versus LEARN

Week-240 minus baseline change is compared between amyloid-positive A4 and amyloid-negative LEARN participants. Within each training fold, a linear age effect is removed and a ridge discriminant turns change into one index, scored on held-out participants. This is an exploratory cohort contrast: LEARN is not A4's randomized placebo arm, and age adjustment does not isolate Alzheimer's effects from treatment, scanner or other cohort differences.

How good is the eval itself

These diagnostics estimate the difference from the reference detectable with 80% power, variation across cross-validation partitions, and agreement of dev and test rankings. Resolution is approximate, not a prospective power guarantee. Test scores for the frozen representations have already been computed.

Protocol

Frozen on 2026-10-01. Changing any of these rules makes a new eval version, and results across versions are not comparable.

  • Participants. A4 mITT and LEARN participants with a baseline T1w scan that passed registration QC (Dice ≥ 0.9 with the template brain) and NeuroQuant volumes: . Each task uses the subset that has its target, the same subset for every representation.
  • Split. One 75/25 dev/test split stratified by cohort, arm, APOE ε4 and tau-substudy membership, plus ten fixed 5-fold assignments of dev. The split file must hash to , so it cannot drift.
  • Probes. Standardized ridge with a fixed penalty grid for a single block; when clinical data are present, one ridge per block combined by stacking, so a wide embedding cannot swamp fifteen clinical features. No tuning per representation.
  • Targets. P1: least-squares PACC slope over every blinded visit (at least 4 visits over 2 years), adjusted for test form. P2: PACC change at week 240 in completers. P3: ATRI's CDR-global progression event by week 252 against event-free follow-up to week 228 or later. Clinical block: age, sex, education, APOE ε4, baseline PACC and its components, MMSE, CFI, CDR-SB, ADL, C3 and log plasma p-tau217.
  • Scoring. Dev scores average the scores from ten cross-validation repeats. Shared participant-bootstrap draws give score and gain intervals: 2,000 draws for P/B/S tasks, 1,000 for C tasks. This page widens differences from SynthSeg using variation across 24 random 1,024-dimensional probes (C1 and C2, but not C3). Score/gain intervals remain bootstrap-only; results.json stores bootstrap intervals before this widening. Test scores come from one fit on all of dev.
  • Test discipline. Test is scored only for representations listed in FROZEN in eval.py. Add a checkpoint there once, when it is final, and report that number.
Using it to hill-climb. Develop against the dev scores. A checkpoint improves on another only when the paired interval excludes zero on P1 (gain or scan alone) without losing on S1–S2. Check B1 and C1–C3 for where the gain comes from. Gate-sized gains (about +0.03 R² over volumetrics) are detectable on dev but not reliably on the 25% test split, so confirm them on an external cohort (ADNI) before claiming them.

Evaluate a new checkpoint

1. From the repo root, add the checkpoint to MODELS in embed.py, then embed cached scans (minutes on 8 GPUs):
   sbatch -p n --qos=high --account=sophont --gres=gpu:1 -c 16 --mem=96G --array=0-7 \
     -o /data/paul/a4/mri/logs/embed_%A_%a.log \
     --wrap 'set -e; pids=""; for j in 0 1 2; do SHARD=$((SLURM_ARRAY_TASK_ID * 3 + j)) uv run --locked python embed.py &
       pids="$pids $!"; done; for pid in $pids; do wait "$pid"; done'
2. Wait for every embedding task to succeed, add the same identifier to MODELS in eval.py, then run the eval:
   sbatch -p c --qos=high --account=sophont -c 64 --mem=256G -o /data/paul/a4/eval/eval_%j.log --wrap "uv run --locked python eval.py"
3. Read /data/paul/a4/eval/report.html. Add only final representation names to FROZEN to obtain test scores.

Glossary

  • A4. The Anti-Amyloid Treatment in Asymptomatic Alzheimer's study: 1,169 cognitively unimpaired people aged 65–85 with elevated brain amyloid, randomized to solanezumab or placebo for 240 weeks. The drug did not slow decline.
  • LEARN. 538 people who screened amyloid-negative, followed untreated, with MRI at baseline and week 240. An observational ageing comparison, not A4's placebo arm.
  • Amyloid and tau. The two proteins that define Alzheimer's disease. Amyloid plaques build up first; tau tangles follow and track symptoms more closely. Both are measured with PET; amyloid load is reported in centiloids, tau as SUVR (uptake relative to a reference region).
  • Plasma p-tau217. A blood test for Alzheimer's pathology, the strongest single predictor of decline in this population. It is part of the clinical baseline, so a scan only counts when it adds to it.
  • PACC. Preclinical Alzheimer Cognitive Composite, the trial's primary outcome: the mean of four z-scored memory and attention tests (0 = average at baseline, lower = worse). Placebo participants declined about 1.1 points over 240 weeks.
  • CDR. Clinical Dementia Rating: 0 = normal, 0.5 = very mild impairment, 1 or more = dementia. CDR-SB is its sum-of-boxes score.
  • mITT. Modified intention-to-treat: randomized participants with a baseline and at least one later assessment.
  • Sessions. MRI visit codes: A4 004 = screening (baseline), 009 = week 12, 066 = week 240; LEARN 006 = baseline, 066 = week 240.
  • Representation. One vector of numbers per scan: regional volumes (SynthSeg, NeuroQuant) or pooled foundation-model tokens (walnut). The eval fits the same probe to every representation.
  • R², ΔR², AUROC. Share of the target's variance a model explains; the extra share a scan adds; the chance that a randomly chosen progressor scores higher than a non-progressor (0.5 = coin flip).
  • d. A standardized difference: how far apart two groups' averages are, in standard deviations.
Sources: ATRI A4/LEARN release; walnut sMRI encoders (hf://medarc/walnut); SynthSeg 2.0; NeuroQuant volumes. Prognostic motivation: Devanarayan et al. 2025; this eval uses different probes and scoring, not a reproduction of that paper. Code and README.
